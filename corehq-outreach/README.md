# CoreHQ – Outreach (Internal)

Multi-Brand Email Campaign CRM (Offer-Driven)

## Locked Product Rules
- One CRM
- One sending email address: hello@corehq.io
- One campaign = one brand
- One contact can belong to many brands
- Offer-driven campaigns (visual, CTA-driven)
- Supports banners, CTAs, featured links, and YouTube previews
- Strong deliverability + compliance (unsubscribe + suppression)
- No AI writing in v1
- Internal use only

## Stack
- Next.js (App Router)
- Supabase (Postgres)
- Supabase Auth (internal admin)
- Resend (email delivery)
- Vercel (hosting)
